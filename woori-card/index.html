우리카드 할인 받는 순서

우리카드 할인은 결제 화면의 할인 쿠폰 입력란에서 적용합니다. 입력란은 전용 페이지로 들어온 경우에만 나타나므로 첫 단계가 가장 중요합니다.

전용 페이지 접속부터 결제까지 5단계

웹과 앱 모두 순서는 같고, 할인 입력란 위치만 다릅니다.

  1. STEP 1

    우리카드 전용 페이지 접속

    우리카드 전용 아고다 페이지로 들어간 뒤 로그인하세요. 일반 링크로 접속하면 할인 입력란이 보이지 않습니다.

  2. STEP 2

    표시 있는 숙소 고르기

    검색 결과에서 '프로모션 상품' 또는 '쿠폰적용 가능' 표시가 붙은 숙소를 고르고, '지금 결제하기' 요금을 선택하세요.

  3. STEP 3

    우리카드 정보 입력

    결제 화면에서 우리카드 번호를 입력하세요. 입력 후 할인 쿠폰 입력란이 나타납니다.

  4. STEP 4

    우리카드 프로모션 적용

    웹은 오른쪽 결제 요약란, 앱은 객실 정보 아래 '할인 쿠폰 사용하기'에서 우리카드 프로모션을 고르세요.

  5. STEP 5

    할인 금액 확인 후 결제

    결제 버튼을 누르기 전에 요약란에 10% 또는 7% 할인 금액이 빠졌는지 확인하세요.

할인이 안 보일 때 확인 순서

아래 순서대로 하나씩 되짚어 보세요.

  1. 접속 경로

    주소창이 우리카드 전용 페이지에서 이어진 것인지 확인하세요. 아니라면 전용 페이지로 다시 들어가 검색하세요.

  2. 숙소 표시와 제외 호텔

    '프로모션 상품'·'쿠폰적용 가능' 표시가 없는 숙소는 제외 호텔일 수 있습니다. 같은 지역의 표시 있는 숙소로 바꿔 보세요.

  3. 객실 요금 형태

    '숙소에서 요금 결제' 요금이면 입력란이 뜨지 않습니다. 같은 객실의 '지금 결제하기' 요금을 고르세요.

  4. 카드 종류와 기간

    해외결제가 되는 개인 카드인지, 예약일과 투숙일이 기간 안인지 확인하세요.

01적용 조건

아고다 우리카드 할인은 체크카드도 되나요?

해외결제가 가능한 해외겸용 체크카드는 됩니다. 국내전용 체크카드와 선불카드, 법인카드는 대상이 아닙니다.

우리카드 할인에 최대 한도가 있나요?

최대 할인 한도와 최소 결제 금액은 표기되어 있지 않습니다. 결제 금액에 10% 또는 7%가 그대로 적용됩니다.

같이 쓸 수 없습니다. 둘 중 최종 결제 금액이 낮은 쪽 하나를 고르세요.

선예약 후지불 요금도 할인되나요?

대상에 포함됩니다. 다만 결제 시점에 별도 수수료와 환전 수수료가 붙을 수 있어 '지금 결제하기'를 권합니다.
